Para regenerarlas:
  1. npm run dev (el script espera el puerto 5250, el de .claude/launch.json)
  2. cd informe-primer-mes && npm i playwright-core
  3. SPIRA_EMAIL=<usuario> SPIRA_PASS=<clave> node capturas.mjs

Seguridad: el script es SOLO lectura contra la base real. Jamás toca
«Confirmar recepción», «Crear recepción», «Verificar» ni «Asociar y agregar»,
no entra al paso Escaneo (escanear escribe), y nunca hoverea los avatares de
pacientes (el tooltip revela el nombre real). En el wizard avanza solo con
estado de cliente y sale con Cancelar → Descartar.

Privacidad verificada: ninguna captura muestra nombres reales de pacientes
(solo iniciales + código IVRS). Los nombres visibles son del staff (médico
tratante, investigador), lo cual es esperado.
