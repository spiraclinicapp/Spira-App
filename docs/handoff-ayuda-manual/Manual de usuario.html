Dispensar una medicación

Del pedido de Coordinación a la entrega al paciente. Spira asigna el lote que vence primero y descuenta el stock al marcarla lista para retirar.

captura · Dispensaciones
0:41

Paso a paso

  1. El pedido llega desde la visita, cuando Coordinación toca «Solicitar dispensación», o lo cargás vos con «Nueva dispensación». Aparece en Solicitadas.
  2. Tocá «Preparar» y escaneá cada unidad con el lector.
  3. Con todo escaneado, tocá «Marcar lista para retirar»: se genera el comprobante, Spira asigna el lote y descuenta el stock.
  4. Cuando el paciente la retira, tocá «Marcar como entregado».
El lote no se escanea. El escaneo valida el producto; el lote lo asigna Spira.

Preguntas frecuentes

El escaneo no se cuenta y Spira te dice por qué: el código no está en el catálogo, el medicamento no está en el pedido, ya tiene todas sus unidades escaneadas o fue sustituido.
